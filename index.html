🔧 GitHub Configuration

Photos are stored in images/ folder of your repo. When you push, the HTML file is updated with all current birthday data baked in. Anyone visiting your GitHub Pages link will see the latest records and photos.
Needs repo scope. Stored in your browser only. Never sent anywhere except GitHub API.
🔧 First-time setup:
  1. Go to github.com → New repo → name it hsin-birthday-buddies (set Public)
  2. Upload this HTML file as index.html to the repo
  3. Create an images/ folder in the repo (add any placeholder file)
  4. Go to Settings → Pages → Deploy from branch → main
  5. Generate a PAT with repo scope → paste above → Save Config
  6. Add records with photos → they auto-upload to images/ folder
  7. Click Push HTML to GitHub → live site updates instantly ✅
